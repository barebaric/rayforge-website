find_subnet_devices()​

find_subnet_devices(
    specs: Sequence[dict[str, object]],
    subnets: Optional[Sequence[tuple[str, int]]] = None,
) -> Awaitable[list[DiscoveredDevice]]

Scan the local subnets for declared TCP ports and confirm each reachable host with its spec's probe.

specs is a list of dicts with the keys id (opaque caller identifier), port, and optionally probe_command (sent to confirm the firmware) and match_prefix (response-line prefix identifying it), plus the declaring driver's display fields (driver_name, label, firmware). Without a probe command any listener on the port is claimed. Returns one DiscoveredDevice per claimed host; the first matching spec claims a host.

subnets overrides the interface enumeration as (address, prefixlen) pairs; None scans the local interfaces.

ParameterTypeDescription
specsSequence[dict[str, object]]
subnetsOptional[Sequence[tuple[str, int]]] = None
ReturnsAwaitable[list[DiscoveredDevice]]

scan_mdns_services()​

scan_mdns_services(
    service_types: Sequence[str],
    browse_window: float = 2.0,
) -> Awaitable[list[dict[str, object]]]

Browse mDNS for the given service types.

Returns one dict per resolved service with the keys service_type (normalized, e.g. _http._tcp), name, host, port, server and txt (a str->str dict). browse_window is the listen time in seconds.

ParameterTypeDescription
service_typesSequence[str]
browse_windowfloat = 2.0
ReturnsAwaitable[list[dict[str, object]]]

scan_serial_ports()​

scan_serial_ports(
    ports: Sequence[str],
    baud_rates: Optional[Sequence[int]] = None,
    timeout: Optional[float] = None,
) -> Awaitable[list[dict[str, object]]]

Probe serial ports for device output.

Opens each port once, tries the baud rates in order and captures everything a talking device sends. Returns one dict per talking port with the keys port, baud_rate and data (bytes). timeout bounds the whole scan; observations collected so far are still returned when it expires.

ParameterTypeDescription
portsSequence[str]
baud_ratesOptional[Sequence[int]] = None
timeoutOptional[float] = None
ReturnsAwaitable[list[dict[str, object]]]

scan_subnet()​

scan_subnet(
    hosts: Sequence[str],
    port: int,
    connect_timeout: float = 0.5,
    concurrency: int = 32,
) -> Awaitable[list[str]]

TCP-connect to port on every host and return the hosts that accept a connection, in input order.

At most concurrency connects run in flight, each bounded by connect_timeout seconds. Intended for explicit, user-requested scans only.
