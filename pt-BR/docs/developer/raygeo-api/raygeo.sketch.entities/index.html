raygeo.sketch.entities

Entity​

The common base class of every entity binding: a nominal Entity type for isinstance checks and annotations. The per-class members live on the subclasses; polymorphism is carried by the Rust-side Entity trait.

array_copy​

array_copy: bool

Whether the entity is part of an array.

constrained​

constrained: bool

Whether the entity's geometry is fully determined by the solver.

construction​

construction: bool

Whether the entity is construction geometry.

fill_color​

fill_color: Optional[tuple[float, float, float, float]]

The fill color, when one is set.

id​

id: int

The unique entity id.

invisible​

invisible: bool

Whether the entity is hidden from output generation.

type​

type: str

The entity kind label ("line", "arc", ...).
