raydriver.ruida

Ruida laser controllers implemented in Rust. RuidaDriver speaks the binary rpascript protocol over USB, UDP or TCP: it runs complete job scripts, executes live motion and job-control commands, polls the controller status and reports the machine state through the uniform driver event surface. Job compilation from Ops lives in the encoder; this session consumes rpascript text.

GlueScript​

The Ruida job authoring and compilation model.

Call the authoring methods to build a job, then stage_gluescript() compiles it into rpascript. stage_gluescript(lines) also replays a persisted transcript.

RuidaDriver(driver.Driver)​

Inherits from driver.Driver; the inherited members are documented on the base class.

A direct connection to a Ruida laser controller.

All async methods return asyncio futures; a typed DriverEvent is delivered to event_callback(event) on the event loop thread. run() and run_raw() take rpascript text; the machine-code encoder produces it from Ops.
