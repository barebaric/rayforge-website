raydriver.grbl.simple

The minimal ping-pong GRBL session: one line at a time, waiting for each ok/error acknowledgement. For hardware where the full driver misbehaves.

GrblSimpleSession​

A minimal GRBL device session using ping-pong communication.

Sends one G-code line at a time and waits for ok before proceeding. No character-counting, no buffer management, no deadlock detection — for hardware where the full [GrblSession][raydriver.grbl.GrblSession] misbehaves.

All async methods return asyncio futures; a typed SessionEvent is delivered to event_callback(event) on the event loop thread.
