raygeo.sketch.registry

Sketch document model.

Model is the registry of points and entities of a sketch document: it stores the same data as the reference entity classes and serializes to and from the same dictionaries (.ryp compatible). Entities are addressed by id; use add_line/add_arc/add_circle/ add_ellipse/add_bezier/add_polygon/add_text_box to extend the document and entity_point_ids/entity_endpoint_ids/entity_type for polymorphic queries.

EntityRegistry​

The sketch document model: points, entities, id allocation.

Serializes to and from the same dictionaries the reference entities produce (.ryp compatible).
