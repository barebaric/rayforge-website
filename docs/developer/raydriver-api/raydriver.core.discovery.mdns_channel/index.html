collect_mdns_recognizers()​

collect_mdns_recognizers(driver_classes: Sequence[Any]) -> list

Pairs every driver whose DISCOVERY spec declares a valid mDNS recognizer with it. Declared service types and fingerprint service types are normalized to their canonical _name._transport form.

ParameterTypeDescription
driver_classesSequence[Any]
Returnslist

find_network_devices()​

find_network_devices(driver_classes: Sequence[Any]) -> Any

Browses the network for every declared service type plus the generic types needed for fingerprinting, and returns one device per confirmed match.

Like every channel, this never raises: failures are logged and bounded by a timeout.

ParameterTypeDescription
driver_classesSequence[Any]
ReturnsAny
