raygeo.sketch

Sketch constraint solving.

Solves 2D geometric constraint systems for parametric sketching: a set of points is moved so that geometric relationships (horizontal, distance, tangency, ...) hold, using the trust-region-reflective least-squares algorithm. The caller describes the problem as a flat list of PointDef entries and constraint objects (see the raygeo.sketch.constraints submodules) and receives solved positions, per-point constrained (fully-determined) flags, and per-constraint conflict indices.
