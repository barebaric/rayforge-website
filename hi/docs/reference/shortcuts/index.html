कीबोर्ड शॉर्टकट

Rayforge में कीबोर्ड शॉर्टकटों का पूर्ण संदर्भ.

प्लेटफ़ॉर्म परंपराएँ
  • Linux/Windows: Ctrl कुंजी
  • macOS: Command कुंजी
  • दस्तावेज़ीकरण Ctrl उपयोग करता है - macOS उपयोगकर्ता Command से बदलें

फ़ाइल ऑपरेशन​

शॉर्टकटक्रियाविवरण
Ctrl+Nनया स्केचनया स्केच बनाएँ
Ctrl+Oखोलेंमौजूदा परियोजना खोलें
Ctrl+Sसहेजेंवर्तमान परियोजना सहेजें
Ctrl+Shift+Sइस रूप में सहेजेंपरियोजना नई फ़ाइल के रूप में सहेजें
Ctrl+Iआयात करेंफ़ाइल आयात संवाद खोलें
Ctrl+Eनिर्यात करेंG-code निर्यात करें
Ctrl+Qछोड़ेंRayforge बंद करें
Ctrl+,वरीयताएँवरीयता संवाद खोलें

शॉर्टकटक्रियाविवरण

Ctrl+Yफिर से करेंपूर्ववत की गई क्रिया दोहराएँ
Ctrl+Shift+Zफिर से करें (वैकल्पिक)वैकल्पिक रीडो शॉर्टकट
Ctrl+Xकाटेंचयन क्लिपबोर्ड पर काटें
Ctrl+Cकॉपी करेंचयन क्लिपबोर्ड पर कॉपी करें
Ctrl+Vपेस्ट करेंक्लिपबोर्ड से पेस्ट करें
Ctrl+Aसभी चुनेंसक्रिय लेयर के सभी आइटम चुनें
Ctrl+Dप्रतिलिपि बनाएँचयनित आइटम की प्रतिलिपि बनाएँ
Deleteहटाएँचयनित आइटम हटाएँ

F123D दृश्य3D पूर्वावलोकन विंडो टॉगल करें
F11सिमुलेशन मोडसिमुलेशन मोड टॉगल करें

Ctrl+Alt+Wवर्कपीस विभाजित करेंवर्कपीस को भागों में विभाजित करें

मशीन ऑपरेशन

मशीन नियंत्रण ऑपरेशन (Home, Frame, Send आदि) में वर्तमान में कोई डिफ़ॉल्ट शॉर्टकट नहीं है लेकिन टूलबार बटनों या मेनू से पहुँचे जा सकते हैं.

Ctrl+Yफिर से करेंटेक्स्ट संपादन दोहराएँ
Ctrl+Aसभी चुनेंसारा टेक्स्ट चुनें
Ctrl+Xकाटेंचयनित टेक्स्ट काटें
Ctrl+Cकॉपी करेंचयनित टेक्स्ट कॉपी करें
Ctrl+Vपेस्ट करेंटेक्स्ट पेस्ट करें

श्रेणी द्वारा त्वरित संदर्भ​

सर्वाधिक उपयोग (शीर्ष 10)​

  1. Ctrl+Z / Ctrl+Y - पूर्ववत/फिर से करें
  2. Ctrl+C / Ctrl+V - कॉपी/पेस्ट
  3. Ctrl+D - प्रतिलिपि बनाएँ
  4. Delete - हटाएँ
  5. Ctrl+A - सभी चुनें
  6. Ctrl+N - नया स्केच
  7. Ctrl+O - खोलें
  8. Ctrl+S - सहेजें
  9. H - वर्कपीस टॉगल करें
  10. F12 - 3D दृश्य

दृश्य और विज़ुअलाइज़ेशन​

  • H - वर्कपीस छिपाएँ/दिखाएँ
  • T - टैब छिपाएँ/दिखाएँ
  • Ctrl+Alt+C - कैमरा टॉगल करें
  • F12 - 3D दृश्य
  • F11 - सिमुलेशन मोड
  • Ctrl+Shift+T - ट्रैवल दृश्य
  • 1, 2, 3, 4, 5, 7 - 3D दृश्य प्रीसेट
  • P - परिप्रेक्ष्य टॉगल

संपादन और रूपांतरण​

  • Ctrl+Z / Ctrl+Y - पूर्ववत/फिर से करें
  • Ctrl+X / Ctrl+C / Ctrl+V - काटें/कॉपी करें/पेस्ट करें
  • Ctrl+D - प्रतिलिपि बनाएँ
  • Delete - हटाएँ
  • Shift+H / Shift+V - क्षैतिज/लंबवत पलटें
  • Ctrl+G / Ctrl+U - समूह बनाएँ/समूह हटाएँ

संरेखण​

  • Shift+Arrow Keys - किनारों से संरेखित करें
  • Shift+Home / Shift+End - केंद्र संरेखित करें
  • Ctrl+Shift+H / Ctrl+Shift+V - वितरित करें
  • Ctrl+Alt+A - पिक्सेल-परफ़ेक्ट

शॉर्टकट अनुकूलित करना​

कस्टम शॉर्टकट

कीबोर्ड शॉर्टकट वर्तमान में हार्डकोडेड हैं. कस्टम शॉर्टकट कॉन्फ़िगरेशन भविष्य के संस्करणों में जोड़ा जा सकता है.

वर्तमान सीमाएँ:

  • स्रोत कोड संशोधित किए बिना शॉर्टकट नहीं बदले जा सकते
  • शॉर्टकट अनुकूलन के लिए कोई GUI नहीं
  • कुछ क्रियाओं पर शॉर्टकट निर्दिष्ट नहीं हो सकते

सुविधा अनुरोध: यदि आपको कस्टम शॉर्टकट चाहिए, तो कृपया GitHub पर एक समस्या खोलें.

सुझाव और युक्तियाँ​

दक्षता सुझाव​

  1. पहले संपादन शॉर्टकट सीखें - Ctrl+Z/Y/C/V/D लगातार उपयोग होते हैं
  2. एकल-कुंजी टॉगल उपयोग करें - त्वरित दृश्य बदलावों के लिए H, T, P
  3. 3D दृश्य शॉर्टकट - तुरंत दृश्य स्विच के लिए 1, 2, 7
  4. संरेखण शॉर्टकट - संरेखण बटन क्लिक करने से Shift+Arrow तेज़ है
  5. सिमुलेशन मोड - निष्पादन त्वरित जाँचने के लिए F11

वर्कफ़्लो शॉर्टकट​

त्वरित संपादन चक्र:

1. नया स्केच (Ctrl+N) या खोलें (Ctrl+O)
2. आइटम व्यवस्थित करें (ऐरो कीज़, संरेखण के लिए Shift+Arrow)
3. पार्टों की प्रतिलिपि बनाएँ (Ctrl+D)
4. 3D में जाँचें (F12)
5. सिमुलेट करें (F11)
6. सहेजें (Ctrl+S) या निर्यात करें (Ctrl+E)

सटीक स्थापना:

1. आइटम चुनें
2. 1mm सरकाने के लिए ऐरो कीज़
3. 10mm छलांगों के लिए Shift+Arrow
4. केंद्रित करने के लिए Shift+Home/End

छिपे हुए शॉर्टकट​

कुछ कम ज्ञात शॉर्टकट:

  • Ctrl+, - वरीयताओं तक त्वरित पहुँच (macOS पर मानक, यहाँ भी काम करता है)
  • Ctrl+Shift+Z - वैकल्पिक रीडो (Ctrl+Y से अधिक पसंद करने वालों के लिए)
  • Ctrl+Alt+A - सटीक स्थापना के लिए पिक्सेल-परफ़ेक्ट स्नैपिंग
  • Ctrl+Alt+T - त्वरित समदूरस्थ टैब स्थापना

प्लेटफ़ॉर्म अंतर​

Linux​

  • मानक Ctrl मॉडिफ़ायर उपयोग करता है
  • सभी शॉर्टकट दस्तावेज़ अनुसार काम करते हैं
  • GTK मानक शॉर्टकट टेक्स्ट फ़ील्डों में लागू होते हैं

Windows​

  • मानक Ctrl मॉडिफ़ायर उपयोग करता है
  • Linux शॉर्टकटों से समरूप
  • Windows-विशिष्ट कीज़ (Win कुंजी) उपयोग नहीं होतीं

macOS​

  • Ctrl (Command) से मैप होता है
  • Alt % (Option) से मैप होता है
  • मानक macOS परंपराएँ लागू होती हैं
  • छोड़ने के लिए Cmd+Q (Ctrl+Q के बजाय)

शॉर्टकट समस्या निवारण​

शॉर्टकट काम नहीं कर रहा​

सामान्य समस्याएँ:

  1. गलत तत्व पर फ़ोकस - सुनिश्चित करें कि टेक्स्ट फ़ील्ड नहीं, कैनवस या मुख्य विंडो फ़ोकस में है
  2. टकराता एप्लिकेशन - कोई अन्य ऐप शॉर्टकट रोक रहा हो सकता है
  3. डेस्कटॉप वातावरण शॉर्टकट - सिस्टम शॉर्टकट अध्यारोहित कर सकते हैं (जैसे, Alt+F4)
  4. नंबर पैड बनाम संख्या पंक्ति - 3D दृश्य शॉर्टकटों के लिए नंबर पैड नहीं, संख्या पंक्ति उपयोग करें

समाधान:

  • फ़ोकस सुनिश्चित करने के लिए कैनवस पर क्लिक करें
  • टकराव के लिए सिस्टम कीबोर्ड शॉर्टकट जाँचें
  • कार्यक्षमता सत्यापित करने के लिए इसके बजाय मेनू क्रिया आज़माएँ

मॉडिफ़ायर कीज़​

यदि Ctrl काम न करे:

  • सत्यापित करें कि Caps Lock बंद है (कुछ सिस्टमों पर बाधा डाल सकता है)
  • कीबोर्ड के दोनों तरफ़ Ctrl आज़माएँ
  • कीबोर्ड लेआउट सेटिंग्स जाँचें

यदि Alt काम न करे:

  • कुछ विंडो मैनेजर विंडो ड्रैगिंग के लिए Alt पकड़ लेते हैं
  • विंडो मैनेजर Alt शॉर्टकट अक्षम करने का प्रयास करें
  • विकल्प के रूप में मेनू आइटम उपयोग करें
