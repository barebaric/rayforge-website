मैक्रो और हुक

Rayforge आपके वर्कफ़्लो अनुकूलित करने के लिए दो शक्तिशाली स्वचालन सुविधाएँ देता है: मैक्रो और हुक. दोनों आपको अपने जॉब में कस्टम G-code जोड़ने देते हैं, लेकिन वे भिन्न उद्देश्य सेवते हैं.

अवलोकन​

सुविधाउद्देश्यट्रिगरउपयोग प्रसंग
मैक्रोपुन: प्रयोज्य G-code स्निपेटमैन्युअल निष्पादनत्वरित कमांड, परीक्षण पैटर्न, कस्टम रूटीन
हुकस्वतः G-code इंजेक्शनजॉब जीवनचक्र घटनाएँस्टार्टअप अनुक्रम, लेयर बदलाव, सफ़ाई

मैक्रो​

मैक्रो नामित, पुन: प्रयोज्य G-code स्क्रिप्ट हैं जिन्हें आप किसी भी समय मैन्युअल रूप से निष्पादित कर सकते हैं.

मैक्रो किसके लिए हैं?​

सामान्य मैक्रो उपयोग प्रसंग:

  • मशीन होम करना - $H तेज़ी से भेजें
  • वर्क ऑफ़सेट सेट करना - G54/G55 स्थितियाँ संग्रहीत और पुनः प्राप्त करें
  • एयर असिस्ट नियंत्रण - एयर असिस्ट चालू/बंद टॉगल करें
  • फ़ोकस परीक्षण - एक त्वरित फ़ोकस परीक्षण पैटर्न चलाएँ
  • कस्टम टूल बदलाव - बहु-लेज़र सेटअप के लिए
  • आपातकालीन रूटीन - त्वरित शटडाउन या अलार्म साफ़
  • सामग्री प्रोबिंग - स्वतः फ़ोकस या ऊँचाई मापन

मैक्रो बनाना​

  1. मशीन सेटिंग्स खोलें:

    • Settings → Machine → Macros पर जाएँ

  2. नया मैक्रो जोड़ें:

    • "+" बटन पर क्लिक करें
    • एक वर्णनात्मक नाम दर्ज करें (जैसे, "Home Machine", "Enable Air Assist")

  3. अपना G-code लिखें:

    • प्रत्येक पंक्ति एक अलग G-code कमांड है
    • टिप्पणियाँ ; या ( से शुरू होती हैं
    • वेरिएबल उपयोग किए जा सकते हैं (नीचे वेरिएबल प्रतिस्थापन देखें)
    • वेरिएबल प्लेसहोल्डर या किसी अन्य मैक्रो का @include(...) संदर्भ डालने के लिए एडिटर के ऊपर टूलबार का उपयोग करें

वेरिएबल प्लेसहोल्डर पॉपओवर वर्तमान संदर्भ में उपलब्ध सभी वेरिएबल सूचीबद्ध करता है:

  1. मैक्रो सहेजें

  2. मैक्रो निष्पादित करें:

    • मैक्रो सूची से, मैक्रो पर क्लिक करें
    • या कीबोर्ड शॉर्टकट निर्दिष्ट करें (यदि समर्थित)

उदाहरण मैक्रो​

सरल: मशीन होम करें​

नाम: Home Machine कोड:

$H
; Waits for homing to complete

उपयोग: काम शुरू करने से पहले त्वरित रूप से मशीन होम करें.

मध्यम: वर्क ऑफ़सेट सेट करें​

नाम: Set G54 to Current Position कोड:

G10 L20 P1 X0 Y0
; Sets G54 work coordinate system origin to current position

उपयोग: वर्तमान लेज़र स्थिति को जॉब मूल के रूप में चिह्नित करें.

उन्नत: फ़ोकस परीक्षण ग्रिड​

नाम: 9-Point Focus Test कोड:

; 9-point grid for finding optimal focus
G21  ; Millimeters
G90  ; Absolute positioning
G0 X10 Y10
M3 S1000
G4 P0.1
M5
G0 X20 Y10
M3 S1000
G4 P0.1
M5
; ... (repeat for remaining points)

उपयोग: बेड पर भिन्न स्थितियों पर त्वरित रूप से फ़ोकस परीक्षण करें.

हुक​

हुक जॉब निष्पादन के दौरान विशिष्ट घटनाओं द्वारा ट्रिगर होने वाले स्वतः G-code इंजेक्शन हैं.

हुक ट्रिगर​

Rayforge इन हुक ट्रिगरों का समर्थन करता है:

ट्रिगरकब चलता हैसामान्य उपयोग
लेयर प्रारंभप्रत्येक लेयर प्रोसेस करने से पहलेटूल बदलाव, शक्ति समायोजन, टिप्पणियाँ
लेयर समाप्तप्रत्येक लेयर प्रोसेस करने के बादप्रगति अधिसूचना, विराम
वर्कपीस प्रारंभप्रत्येक वर्कपीस प्रोसेस करने से पहलेपार्ट क्रमांकन, संरेखण निशान
वर्कपीस समाप्तप्रत्येक वर्कपीस प्रोसेस करने के बादकूलडाउन, निरीक्षण विराम
जॉब-स्तरीय G-code

जॉब प्रारंभ और अंत G-code हुक के बजाय डायलेक्ट की प्रीएम्बल और पोस्टस्क्रिप्ट सेटिंग्स के माध्यम से कॉन्फ़िगर होता है. विवरण के लिए G-code सेटिंग्स देखें.

हुक बनाना​

  1. मशीन सेटिंग्स खोलें:

    • Settings → Machine → Hooks पर जाएँ

  2. एक ट्रिगर चुनें:

    • वह घटना चुनें जब यह हुक चलना चाहिए

  3. अपना G-code लिखें:

    • हुक कोड ट्रिगर बिंदु पर जोड़ा जाता है
    • गतिशील मानों के लिए वेरिएबल उपयोग करें (नीचे देखें)

  4. सक्षम/अक्षम करें:

    • हुक को हटाए बिना चालू/बंद टॉगल करें

उदाहरण हुक​

लेयर प्रारंभ: टिप्पणी जोड़ें​

ट्रिगर: लेयर प्रारंभ कोड:

; Starting layer: {layer_name}
; Layer index: {layer_index}

उद्देश्य: G-code को डिबगिंग के लिए अधिक पठनीय बनाता है.

वर्कपीस प्रारंभ: पार्ट क्रमांकन​

ट्रिगर: वर्कपीस प्रारंभ कोड:

; Part: {workpiece_name}
; Part {workpiece_index} of {total_workpieces}

उद्देश्य: बहु-पार्ट जॉब में प्रगति ट्रैक करें.

हुक निष्पादन क्रम​

2 लेयरों वाले जॉब के लिए, प्रत्येक में 2 वर्कपीस:

  [Layer Start Hook] (Layer 1)
    [Workpiece Start Hook] (Workpiece 1)
      ... workpiece 1 G-code ...
    [Workpiece End Hook] (Workpiece 1)
    [Workpiece Start Hook] (Workpiece 2)
      ... workpiece 2 G-code ...
    [Workpiece End Hook] (Workpiece 2)
  [Layer End Hook] (Layer 1)
  [Layer Start Hook] (Layer 2)
    [Workpiece Start Hook] (Workpiece 3)
      ... workpiece 3 G-code ...
    [Workpiece End Hook] (Workpiece 3)
    [Workpiece Start Hook] (Workpiece 4)
      ... workpiece 4 G-code ...
    [Workpiece End Hook] (Workpiece 4)
  [Layer End Hook] (Layer 2)

वेरिएबल प्रतिस्थापन​

मैक्रो और हुक दोनों गतिशील मान जोड़ने के लिए वेरिएबल प्रतिस्थापन समर्थन करते हैं.

उपलब्ध वेरिएबल​

वेरिएबल {variable_name} सिंटैक्स उपयोग करते हैं और G-code जनरेशन के दौरान बदल दिए जाते हैं.

जॉब-स्तरीय वेरिएबल:

वेरिएबलविवरणउदाहरण मान
{job_name}वर्तमान जॉब/दस्तावेज़ का नाम"test-job"
{date}वर्तमान तिथि"2025-10-03"
{time}वर्तमान समय"14:30:25"

लेयर-स्तरीय वेरिएबल:

वेरिएबलविवरणउदाहरण मान
{layer_name}वर्तमान लेयर का नाम"Cut Layer"
{layer_index}वर्तमान लेयर का शून्य-आधारित सूचकांक0, 1, 2...
{total_layers}जॉब में कुल लेयरें3

वर्कपीस-स्तरीय वेरिएबल:

वेरिएबलविवरणउदाहरण मान
{workpiece_name}वर्कपीस का नाम"Circle 1"
{workpiece_index}वर्तमान वर्कपीस का शून्य-आधारित सूचकांक0, 1, 2...
{total_workpieces}कुल वर्कपीस संख्या5

मशीन वेरिएबल:

वेरिएबलविवरणउदाहरण मान
{machine_name}मशीन प्रोफ़ाइल का नाम"My K40"
{max_speed}अधिकतम कटिंग गति (mm/min)1000
{work_width}कार्य क्षेत्र चौड़ाई (mm)300
{work_height}कार्य क्षेत्र ऊँचाई (mm)200

उदाहरण: प्रगति अधिसूचना​

हुक: लेयर प्रारंभ कोड:

; ========================================
; Layer {layer_index} of {total_layers}: {layer_name}
; Job: {job_name}
; Time: {time}
; ========================================

G-code में परिणाम:

; ========================================
; Layer 0 of 3: Cut Layer
; Job: test-project
; Time: 14:30:25
; ========================================

उन्नत उपयोग प्रसंग​

बहु-टूल सेटअप​

कई लेज़र या टूल वाली मशीनों के लिए:

हुक: वर्कपीस प्रारंभ कोड:

; Select tool for workpiece {workpiece_name}
T{tool_number}  ; Tool change command (if supported)
G4 P1           ; Wait for tool change

सशर्त विराम​

निरीक्षण के लिए वैकल्पिक विराम जोड़ें:

हुक: लेयर समाप्त कोड:

; M0  ; Uncomment to pause after each layer for inspection

प्रति लेयर एयर असिस्ट​

प्रति-लेयर आधार पर एयर असिस्ट नियंत्रित करें:

हुक: लेयर प्रारंभ (कटिंग लेयरों के लिए) कोड:

M8  ; Air assist ON

हुक: लेयर प्रारंभ (उत्कीर्णन लेयरों के लिए) कोड:

M9  ; Air assist OFF (prevents dust scattering for engraving)
लेयर-विशिष्ट हुक

Rayforge वर्तमान में प्रति-लेयर हुक अनुकूलन समर्थन नहीं करता. इसे हासिल करने के लिए सशर्त G-code या अलग मशीन प्रोफ़ाइल उपयोग करें.

सुरक्षा विचार​

उत्पादन से पहले परीक्षण करें

वास्तविक जॉब पर चलाने से पहले हमेशा मैक्रो और हुक को सिमुलेशन मोड में या लेज़र अक्षम करके परीक्षण करें. गलत कॉन्फ़िगर किया गया G-code:

  • मशीन को सीमाओं में टकरा सकता है
  • लेज़र को अप्रत्याशित रूप से चला सकता है
  • सामग्री या उपकरण को नुकसान पहुँचा सकता है

सुरक्षा जाँच सूची:

  • मैक्रो में फ़ीडरेट सीमाएँ शामिल हैं (F पैरामीटर)
  • मैक्रो स्थिति सीमाएँ जाँचते हैं
  • सिमुलेशन में या लेज़र अक्षम करके परीक्षित
