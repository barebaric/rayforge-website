任务计数器

文本框会解析 {...} 模板（参见参数与表达式）。除了草图参数和内置函数之外，项目还有一个随每次任务变化的任务计数器，因此无需每次修改文本即可雕刻带编号的铭牌、吊牌和标签。

任务计数器​

在文本框中使用 {counter}。它是一个整数，因此可以用格式说明符控制其外观：

  • {counter} — 7
  • {counter:04d} — 0007，四位数并补前导零
  • No. {counter:03d} — No. 007

打开**工具 → 任务计数器…**来设置计数器：

  • 当前值 — 下一次任务开始使用的编号。
  • 起始值 — 重置时返回的值。
  • 递增量 — 每个副本和每次任务的增量。
  • 到达结束值后循环 / 结束值 — 超过结束值后，计数器从起始值继续。
  • 每次任务后递增 — 发送到机器的任务完成后，计数器递增。取景、指示光试运行和已取消的任务不会改变它。
  • 导出 G-code 后递增 — 导出 G-code 时也递增，适用于从存储卡运行的任务。

下一次任务分组会预览下一次任务将使用的编号。上一个和下一个将计数器移动一次任务，重置返回起始值。每次更改（包括自动递增）都会记入撤销历史并保存在项目中。

为副本编号​

每个工件都有一个变量偏移。偏移为 n 的副本显示当前编号之后第 n 个副本的编号。网格或环形阵列会自动为其副本分配递增的偏移，因此一个包含 20 块铭牌的阵列会雕刻 20 个连续编号，下一次任务从第 21 个继续。

在草图内部创建的阵列则不同：它们的副本属于同一个工件，全部显示相同的编号。如需为副本编号，请改为在画布上创建阵列。

对于手动放置的副本，全部选中后选择排列 → 阵列 → 为副本编号：偏移按阅读顺序分配，行从上到下，每行从左到右。

计数器按任务中的副本数递增：即最大变量偏移加一。

G-code 中的计数器​

计数器也可用于 G-code 钩子、宏以及方言的前言和后记：

  • {counter} 是作业开始时的值。
  • {workpiece.counter} 是当前工件的值，因此工件开始钩子可以为每个副本单独标注。
  • 格式说明在这里同样有效：{counter:04d}。

例如，前言行 ; Job {counter:04d} 打印起始编号，工件开始钩子中的 ; Part {workpiece.counter:04d} 打印每个零件的编号。

读取计数器的新草图副本会自动编号：下一个实例获得下一个偏移量。要重新编号已放置的副本，请选中它们并使用 排列 → 阵列 → 编号副本。
